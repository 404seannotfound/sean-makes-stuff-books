# Sean Makes Stuff — Books

The books shelf of [sean-makes-stuff.com](https://sean-makes-stuff.com), split into its
own GitHub Pages site (books.sean-makes-stuff.com) because the audiobooks pushed the main
site past the 1GB Pages limit. Illustrated novels, picture books, and tutorials — each with
storyboard art and a multi-voice audiobook from the scriptorium pipeline.
